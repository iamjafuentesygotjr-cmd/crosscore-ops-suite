### PROFILE CLICK → PERSONAL CHAT FUNCTIONALITY Please fix the profile interaction inside both **Group Chats (GC)** and **Personal Messages**. Currently, when I click the **circular profile photo/avatar** of a user inside a message, nothing happens. The profile circle should be interactive and allow users to easily start a **personal/1-on-1 chat (PM)** with that person. #### Required Behavior **1. Group Chat (GC)** * When I click a user's circular profile photo/avatar or name inside a GC: * Open that user's profile or profile pop-up. * Show a clear **"Message" / "Start Personal Chat"** option. * Clicking it should open a **1-on-1 personal chat** with that user. * If a personal conversation already exists, open the existing conversation instead of creating a duplicate. * Load the existing conversation history and automatically show the latest message. **2. Personal Messages** * When I click the user's circular profile photo/avatar or name inside an existing personal message: * The profile should still be clickable. * Allow the user to view the person's profile. * Provide the option to continue/open the personal chat. * The interaction should not be broken or non-functional. **3. Direct Avatar Click** The **circular profile photo itself must be clickable**, not just the person's name. Example: **Click Profile Circle → View Profile → Message → Open 1-on-1 Chat** The profile circle should have proper hover/click behavior so users can tell that it is interactive. **4. Prevent Duplicate Chats** Before creating a new PM: * Check whether a 1-on-1 conversation already exists between the two users. * If it exists, open that conversation. * Do not create multiple duplicate personal conversations between the same users. **5. Real-Time Behavior** The new personal chat must follow the existing real-time messaging system: **User clicks profile → selects Message → PM opens → sends message → message saves to database → recipient receives it in real time → notification is generated if enabled → notification opens the exact PM.** No manual refresh should be required. **6. Desktop + Mobile** Make sure this works consistently on: * Desktop web * Mobile browser * Mobile app The avatar/profile interaction should remain clickable and usable on smaller screens. ### Acceptance Criteria * Clicking a user's profile circle in a GC works. * Clicking a user's profile circle in a personal message works. * Users can start/open a personal chat directly from the profile. * Existing PMs are reused instead of duplicated. * The correct user is always selected. * The profile click does not interfere with opening/scrolling the message. * PM messages sync in real time. * Notifications correctly point to the new/existing PM. * No refresh is required at any step.
